  • Bellman/Held-Karp (DP)
    A bottom-up dynamic programming algorithm which solves the Hamiltnonian path problem.
    Algorithm memoizes the results in a table \(DP[S][v]\) where \(S\) is a subset of vertices and \(v\) is a vertex in \(S\). It is stored to TRUE if there is a Hamiltonian path that visits all vertices in \(S\) and ends at vertex \(v\).
    The recurrence relation is given as: \[ DP[S][v] = \bigvee_{\substack{u \in S \setminus \{v\}\\(u,v) \in E}} (DP[S - \{v\}][u]), \] and the base case is: \[ DP[\{v\}][v] = TRUE, \forall v \in V \] A Hamiltonian path in a graph \(G=(V,E)\) exists if \(DP[V][v]\) is TRUE for any vertex \(v \in V\).
    Time complexity: \(O(n^2 2^n)\)
    Space complexity: \(O(n 2^n)\)
  • Bax-Karp (Inclusion-Exclusion)
    Bax-Karp algorithm calculates the number of all Hamiltonian paths in a graph using the principle of inclusion-exclusion.
    The formula used is given as: \[ H_{n-1} (v_i, v_j) = \sum_{S \subseteq V} (-1)^{|S|} \cdot |W_S|, \] \[ |W_S| = A^{n-1}_{S}, \] where \(H_{n-1}(v_i, v_j)\) is the number of Hamiltonian paths from \(v_i\) to \(v_j\), \(V\) is the set of vertices, \(S\) is a subset of vertices, and \(W_S\) is the number of walks of length \(n-1\) in the graph with vertices in \(S\) removed, and \(A_{S}\) is the adjacency matrix of the graph with vertices in \(S\) removed.
    Hamiltonian path exists if \(H_{n-1}(v_i, v_j) > 0\) for any pair of vertices \(v_i, v_j \in V\).
    If one wants to find Hamiltonian cycles, the only thing that needs to be changed is the length of the walks, which should be \(n\) instead of \(n-1\).
    Time complexity: \(O(n^3 \log n \cdot 2^n)\)
    Space complexity: \(O(n^2)\)
